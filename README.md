# Flutter Project

A Flutter application where users can log in, browse and search products, view product detail pages, and manage their shopping cart.

---

## Features

- Login with username and password (password must be at least 6 characters)
- Product listing and search
- Product detail page
- Add and remove products from cart

---

## Flutter Version


Flutter 3.41.9 |
Dart 3.11.5 |
DevTools 2.54.2 |

---

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/enestalhazor/flutter_project.git
   cd flutter_project
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the application:**
   ```bash
   flutter run
   ```

> Make sure a device or emulator is connected and running.
